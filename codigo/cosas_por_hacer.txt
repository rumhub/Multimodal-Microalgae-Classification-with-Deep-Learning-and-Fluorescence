En machine learning, cualquier paso de preprocesado que dependa de los datos (como calcular percentiles para filtrar outliers) debe calcularse **solo usando el conjunto de entrenamiento** para evitar *data leakage*. Primero se divide el dataset en **train y test**, después se calculan los percentiles u otros parámetros únicamente con los datos de **train**, y esos mismos valores se usan para filtrar tanto el **train** como el **test** y los datos nuevos en producción. Por tanto, es importante **guardar los valores calculados (por ejemplo p1 y p95)** para poder aplicar exactamente el mismo filtrado cuando el modelo se evalúe o se utilice con datos nuevos.
